# Threadpoolctl

On WASI, inspect the curated shared providers mounted in the guest's `/lib`.
Use upstream native controllers through virtual `ctypes.CDLL` with supported
loader flags. This binds available guest providers rather than an ELF link map;
it can load a mounted provider. Other platforms retain upstream discovery.
An installation without native providers can return an empty list. Scikit-learn
qualifies real OpenBLAS version/thread reporting and the limit context with its
SciPy dependency. Optional OpenMP libraries are unqualified.
