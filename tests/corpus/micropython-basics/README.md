# MicroPython language basics sample

This corpus contains unchanged files from `tests/basics` in MicroPython commit
`09f5bb447504a058376c62fe991b3613531837e6`. The upstream project is MIT licensed; the license text
is included beside this file. Each case records its upstream path, commit, content hash, and checked
CPython output in `manifest.json`.

The frozen sample spans expressions, control flow, functions, classes, closures, comprehensions,
collections, integers, generators, and exception handling. MicroPython-specific and host-dependent
tests were excluded. The corpus is a compatibility workload, not a claim that shellsim implements
the complete MicroPython or CPython language.
